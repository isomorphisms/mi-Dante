# Infierno bilingüe

Esta capa sirve para comparar el italiano con Aranda y Sanjuán.

No se fuerza una falsa correspondencia verso-a-verso: Dante está en tercetos y A&S traduce en prosa. La unidad de alineación será el **pasaje semántico**; cada bloque conservará además los números de verso italianos.

La edición principal de lectura seguirá siendo el castellano directo de A&S. Esta capa existe para estudio, subtraducción y futuras ediciones enfrentadas.
