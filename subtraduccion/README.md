# Subtraducción

El corpus de trabajo empieza por el libro completo **Infierno**. Los cantos son unidades de avance, no el límite del análisis.

## Capas

1. **Italiano de Dante**: texto fuente intacto.
2. **Aranda y Sanjuán**: traducción histórica intacta.
3. **Bilingüe**: ambos textos reunidos para comparación, sin fingir una equivalencia verso-a-verso donde A&S traduce en prosa.
4. **Subtraducción**: notas sobre decisiones recurrentes del traductor e interpolaciones nuestras cuando una alternativa mejora algo identificable.
5. **Ediciones**: salidas de lectura. La edición castellana directa de A&S es la principal; las ediciones bilingües sirven para estudio.

## Qué registrar

Para cada pasaje que lo merezca:

- qué conserva A&S;
- qué omite;
- qué explicita;
- qué desplaza;
- qué transforma;
- qué gana o pierde en castellano;
- vocabulario decisivo;
- una interpolación sólo cuando aporte una mejora concreta.

No se reduce el análisis a «literal / infiel». El objetivo es descubrir el sistema de decisiones de la traducción a lo largo del libro.
